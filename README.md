# iFranko — Магазин iPhone

Статичний сайт магазину iPhone з Node.js-бекендом, базою даних SQLite та зручним Trade-In калькулятором.
Фронтенд написаний на чистому HTML, CSS та JavaScript — без React, TypeScript чи будь-яких фреймворків.

## Огляд проекту

**iFranko** — це інтернет-магазин, що спеціалізується виключно на iPhone. Сайт дозволяє переглядати каталог нових та вживаних телефонів, фільтрувати та шукати моделі, оформлювати замовлення, а також оцінювати вартість свого iPhone за програмою Trade-In.

Усі замовлення та заявки Trade-In зберігаються в локальній базі даних SQLite.

## Встановлення та запуск

### 1. Встановити залежності

```bash
npm install
```

### 2. Запустити сервер

```bash
node server.js
```

Після запуску сервер буде доступний за адресою:

```
http://localhost:3000
```

База даних `shop.db` створиться автоматично при першому запуску.

### Альтернатива: відкрити без сервера

Якщо потрібен лише статичний перегляд без збереження замовлень — відкрий `public/index.html` напряму в браузері. У такому режимі API-запити (оформлення замовлень та Trade-In) не будуть збережені в базі.

## Сторінки та функціональність

### `index.html` — Головна сторінка

Лендінг-сторінка з описом переваг магазину та трьома кнопками для швидкої навігації:

- **Нові iPhone** → переходить на `catalog.html?status=new`
- **Вживані (Б/У)** → переходить на `catalog.html?status=used`
- **Оцінити Trade-In** → переходить на `trade-in.html`

---

### `catalog.html` — Каталог

Повний список доступних iPhone з декількома рівнями фільтрації.

**Фільтри:**

- **Стан** (кнопки-чіпи): Усі / Новий / Вживаний (Б/У)
- **Модель** (бічна панель): iPhone 11, 12, 13, 14, 15, 16, 17, SE 2022 та їх Pro/Pro Max/Plus/Air/e варіанти
- **Пошук** (текстове поле): пошук за назвою моделі, обсягом пам'яті, кольором тощо

**URL-параметри:**

Каталог підтримує попередню фільтрацію через URL. Це дозволяє кнопкам на головній одразу відкривати відповідний список:

```
catalog.html            — показати всі iPhone
catalog.html?status=new — відразу показати тільки нові
catalog.html?status=used — відразу показати тільки вживані
```

**Картка товару:**

Кожен товар відображає фото, назву моделі, обсяг пам'яті, стан, ціну та кнопку «Купити». При натисканні «Купити» відкривається форма з полями Ім'я та Телефон, замовлення надсилається на сервер і зберігається в базі.

---

### `trade-in.html` — Trade-In

Сторінка для розрахунку та оформлення обміну старого iPhone на новий з доплатою.

Калькулятор дозволяє:

- Обрати модель свого поточного iPhone (той, що здаєш)
- Обрати бажану нову модель (та, що хочеш отримати)
- Побачити орієнтовну суму доплати
- Відправити заявку (ім'я, телефон), яка зберігається в базі

## API-ендпоінти

Сервер надає два POST-ендпоінти для збереження заявок.

### `POST /api/order` — Оформити замовлення

Зберігає замовлення з каталогу.

**Тіло запиту (JSON):**

```json
{
  "name": "Іван",
  "phone": "+380501234567",
  "model": "iPhone 16 Pro Max",
  "price": "89990"
}
```

**Відповідь:**

```json
{ "success": true, "message": "Замовлення успішно записано в БД!" }
```

---

### `POST /api/trade-in` — Подати заявку Trade-In

Зберігає заявку на обмін iPhone.

**Тіло запиту (JSON):**

```json
{
  "name": "Марія",
  "phone": "+380671234567",
  "giveModel": "iPhone 13",
  "getModel": "iPhone 16",
  "topup": "25000"
}
```

**Відповідь:**

```json
{ "success": true, "message": "Обмін успішно записано в БД!" }
```

## База даних

Файл `shop.db` (SQLite) створюється автоматично при запуску сервера. Містить дві таблиці:

### `orders` — замовлення з каталогу

| Поле | Тип | Опис |
|---|---|---|
| `id` | INTEGER | Автоматичний ідентифікатор |
| `name` | TEXT | Ім'я покупця |
| `phone` | TEXT | Номер телефону |
| `model` | TEXT | Модель iPhone |
| `price` | TEXT | Ціна |
| `created_at` | DATETIME | Час оформлення замовлення |

### `tradeins` — заявки Trade-In

| Поле | Тип | Опис |
|---|---|---|
| `id` | INTEGER | Автоматичний ідентифікатор |
| `name` | TEXT | Ім'я клієнта |
| `phone` | TEXT | Номер телефону |
| `give_model` | TEXT | Модель, яку здають |
| `get_model` | TEXT | Модель, яку хочуть отримати |
| `topup` | TEXT | Сума доплати |
| `created_at` | DATETIME | Час подачі заявки |
